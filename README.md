# Sudoku Mobile

Sudoku Mobile es una aplicación multiplataforma diseñada para dispositivos móviles que permite disfrutar del clásico juego de lógica de números en cualquier lugar. Ofrece una interfaz intuitiva, múltiples niveles de dificultad y herramientas de asistencia para mejorar la experiencia de resolución de acertijos.

## Características Principales (Features)

- **Múltiples Niveles de Dificultad**: Desafíos adaptados para principiantes y jugadores avanzados (Fácil, Medio, Difícil, Experto).
- **Interfaz Intuitiva y Moderna**: Diseño optimizado para pantallas táctiles con controles fluidos.
- **Sistema de Notas / Lápiz**: Permite anotar posibles números en las celdas tal como en el papel.
- **Validación en Tiempo Real**: Opción para comprobar errores o movimientos incorrectos sobre la marcha.
- **Temporizador y Estadísticas**: Seguimiento del tiempo de resolución y récord personal por dificultad.

## Tecnologías Utilizadas

- **Framework / Core**: React Native / Flutter (o tecnología móvil correspondiente)
- **Lenguaje**: JavaScript / TypeScript / Dart
- **Gestión de Estado**: Context API / Redux / Provider
- **Estilos**: StyleSheet / Tailwind / CSS Modules
